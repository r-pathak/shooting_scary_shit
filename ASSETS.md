# Asset Download Instructions

Some large assets are not included in the repo. Download them from Mixamo:

## Required Downloads from [Mixamo](https://www.mixamo.com)

### 1. Zombie Character (zombie_idle.fbx)
1. Go to Mixamo → Characters → Search "Zombie" or "Romero"
2. Select an idle animation
3. Download as **FBX** with **"With Skin"** checked
4. Save to `public/zombie_idle.fbx`

### 2. Die Animation (zombie_die.fbx)
1. Search animations for "Dying" or "Death"
2. Download as **FBX** **WITHOUT** "With Skin" (just animation)
3. Save to `public/zombie_die.fbx`

### 3. Environment (env.glb) - Optional
The environment model. You can use any GLB environment or skip it.

## Small Assets (included in repo)
- `zombie_attack.fbx` - Attack animation
- `zombie_walk.fbx` - Walk animation
- `grass_texture.jpeg` - Ground texture
- `dirt_texture.jpg` - Ground texture
- `tree_pine.glb` - Tree model
- `rock_large.glb` - Rock model
- `skybox.hdr` - Sky environment
